# Fraymus Living Systems

Living code and digital life applications.

## Applications

- **LazarusEngine** - Lazarus Engine - Digital Resurrection
- **LogicCircuit** - Logic Circuit - Digital Logic Gates
- **BioNode** - BioNode - Digital Biological Cell
- **LivingMindDemo** - Living Mind Demo - Consciousness Simulation
- **SleepCycleDemo** - Sleep Cycle Demo - Digital Sleep Patterns
- **TesseractDemo** - Tesseract Demo - 4D Visualization

## Dependencies

- LWJGL 3.3.3 (OpenGL, GLFW, STB)
- ImGui Java 1.86.11
- JOML 1.10.5
- Core living code framework

## Build

```bash
cd Asset-Manager
./gradlew build
```

## Run Living Systems Apps

```bash
./gradlew runLazarus          # Run Lazarus Engine
./gradlew runLogicCircuit     # Run Logic Circuit
./gradlew runBioNode          # Run BioNode
./gradlew runLivingMind      # Run Living Mind Demo
./gradlew runSleepCycle      # Run Sleep Cycle Demo
./gradlew runTesseract       # Run Tesseract Demo
```

## Requirements

- Java 21
- Gradle 9.2+
